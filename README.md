# Bet Master Labs

Public records desk for people who publish picks. Information only. No sportsbook. No wagering.

Founder & CEO: **Nate Schafer**

## What this is

- Directory and leaderboard across 18 sports
- Trust Index (`BML-TRUST-1`) with a published sample floor of 150 bets
- Verification tiers: audit, ticket, tracked
- Free email profiles with removable lookup history
- Model card and Verify-this provenance on headline numbers

Rank cannot be purchased. Optional support never moves the board.

## Model

See the in-app **Method** page. Version `2026.09.02`.

Weights: sample 28%, close-line value 32%, units 22%, settled hit rate 18%.
